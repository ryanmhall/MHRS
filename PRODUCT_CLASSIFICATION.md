# 1. Data

**Where is it stored and for how long?**

Data will first be stored onboard the microcontroller memory until it is transfered to another device, such as a laptop or mobile phone. 

Data that is transferred to a device, will be stored on a cloud drive. 

# 2. Users and Markets

The users of this device will primiarly be athletes, but this technology can be used by anyone with a wearable device. 

The data acquistion software and hardware can be used in any country or language due to the universal nature of the signals and date. 
However, the instructions and reports will be written in english.
